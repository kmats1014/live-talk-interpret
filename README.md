# Live Talk Interpret — 双方向リアルタイム通訳会話

海外の方とリアルタイムに双方向で会話できるサーバーレスWeb通訳アプリです。  
日本語・英語・タガログ語・インドネシア語に対応し、日常会話からビジネス、教会での交わりまで幅広く使えます。

## 公開サイト
https://kmats1014.github.io/live-talk-interpret/

## 主な機能
- **🌐 ルーム会話モード（2端末〜多人数）**：QRコード/URLで相手を招待。相手はアプリ不要・APIキー不要でブラウザから即参加できます（URLハッシュ鍵 `#key=...` による E2E 暗号化対応）。
- **🤝 1端末対面モード**：1台のスマホ/PCをテーブルに置いて交互に話せます（相手側180°反転表示対応）。
- **🎭 会話トーン＆用語集切替**：日常会話 / 丁寧・ビジネス / 教会・交わりのトーン切替と、教会用語集 ON/OFF。
- **🔇 字幕メイン＋オンデマンド音声**：必要な吹き出しだけ `🔊` で再生、または自動読み上げON（再生中はハウリング防止のためマイク自動一時停止）。
